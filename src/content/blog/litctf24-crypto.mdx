## crypto/simple otp

_552 solves / 110 points_

> We all know OTP is unbreakable...

We are given `main.py`:

```py=
import random

encoded_with_xor = b'\x81Nx\x9b\xea)\xe4\x11\xc5 e\xbb\xcdR\xb7\x8f:\xf8\x8bJ\x15\x0e.n\\-/4\x91\xdcN\x8a'

random.seed(0)
key = random.randbytes(32)
print(key)
```

The key is generated through random, but it is seeded to 0. We can run the program to get the key:

```shellsession
$ python3 main.py
b'\xcd\x07,\xd8\xbeo\x9fb\xacL\t\xc2\x82\x06\xe7\xe3U\x94\xaak4/]\n:^HB\xfa\xb4(\xf7'
```

Get hex of the string using cyberchef:
![cyberchef unescape string + to hex](https://i.sportshead.dev/nsg8p86j.png)

Doing the same for the key, we get the two hex strings:

```
cd 07 2c d8 be 6f 9f 62 ac 4c 09 c2 82 06 e7 e3 55 94 aa 6b 34 2f 5d 0a 3a 5e 48 42 fa b4 28 f7
81 4e 78 9b ea 29 e4 11 c5 20 65 bb cd 52 b7 8f 3a f8 8b 4a 15 0e 2e 6e 5c 2d 2f 34 91 dc 4e 8a
```

Now we can xor them in cyberchef:

## crypto/pope shuffle

_262 solves / 121 points_

> it's like caesar cipher but better. Encoded: ࠴࠱࠼ࠫ࠼࠮ࡣࡋࡍࠨ࡛ࡍ࡚ࡇ࡛ࠩࡔࡉࡌࡥ

dcode.fr tells us this looks like an [ASCII Shift Cipher](https://www.dcode.fr/ascii-shift-cipher):
![dcode.fr cipher identifier](https://i.sportshead.dev/y3p6lmt.png)

However, we can see that this text is not ascii, but unicode. Let's see if we can do any shifts ourselves:

```ts=
const s = "࠴࠱࠼ࠫ࠼࠮ࡣࡋࡍࠨ࡛ࡍ࡚ࡇ࡛ࠩࡔࡉࡌࡥ";
const a = [...s];
console.log(a)
```

```shellsession
$ bun run pwn.ts
[
  2100, 2097, 2108, 2091, 2108, 2094, 2147, 2123, 2125, 2088, 2139, 2125, 2138, 2119,
  2139, 2089, 2132, 2121, 2124, 2149
]
$ node
Welcome to Node.js v21.2.0.
Type ".help" for more information.
> "L".charCodeAt(0)
76
> 2100-76
2024
```

Seems like a shift of 2024. Let's modify our script:

```ts=
const s = "࠴࠱࠼ࠫ࠼࠮ࡣࡋࡍࠨ࡛ࡍ࡚ࡇ࡛ࠩࡔࡉࡌࡥ";
const a = [...s];

console.log(
    a
        .map((x) => x.charCodeAt(0) - 2024)
        .map((x) => String.fromCharCode(x))
        .join(""),
);
```

```shellsession
$ bun run pwn.ts
LITCTF{ce@ser_sAlad}
```
