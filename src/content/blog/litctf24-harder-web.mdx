A quick comparison shows that the expected amounts of colours seem about right, since we can see quite a bit of green and blue in the challenge pixels. We can reassemble this pattern by sorting the pixels such that the hue of each pixel increases along the diagonal of the grid.

One possible way to accomplish this would be to "unwrap" the grid into a 1d array, sort the array, then reassemble the grid. By tracking the original positions of each pixel that is now sorted, we can then swap the pixels into their correct location.

Looks like the unwrapping works. Now we need to get the pixels sorted. We first need to extract the hue value from the RGB hex, which we can do with this [algorithm from StackOverflow](https://stackoverflow.com/a/23094494):

```ts
/**
 * Convert rgb hex to hue
 * @param {string} hex - #ff0000
 * @returns {number} hue - 0-360
 */
function rgbToHue(hex: string): number {
    const r = parseInt(hex.slice(1, 3), 16) / 255;
    const g = parseInt(hex.slice(3, 5), 16) / 255;
    const b = parseInt(hex.slice(5, 7), 16) / 255;

    const min = Math.min(r, g, b);
    const max = Math.max(r, g, b);

    const delta = max - min;
    if (delta === 0) {
        return 0;
    }

    let hue = 0;
    if (r === max) {
        hue = (g - b) / delta;
    } else if (g === max) {
        hue = 2 + (b - r) / delta;
    } else if (b === max) {
        hue = 4 + (r - g) / delta;
    }

    hue *= 60;
    return hue;
}
```
