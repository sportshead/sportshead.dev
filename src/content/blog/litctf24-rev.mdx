## rev/Burger Reviewer

_254 solves / 122 points_

> Try to sneak a pizza into the burger reviewer!

The attached file is a Java program `Burgers.java`:

```java=
import java.util.*;

public class Burgers {

	public static boolean bun(String s) {
		return (s.substring(0, 7).equals("LITCTF{") && s.charAt(s.length()-1) == '}');
	}

	public static boolean cheese(String s) {
		return (s.charAt(13) == '_' && (int)s.charAt(17) == 95 && s.charAt(19) == '_' && s.charAt(26)+s.charAt(19) == 190 && s.charAt(29) == '_' && s.charAt(34)-5 == 90 && s.charAt(39) == '_');
	}

	public static boolean meat(String s) {
		boolean good = true;
		int m = 41;
		char[] meat = {'n', 'w', 'y', 'h', 't', 'f', 'i', 'a', 'i'};
		int[] dif = {4, 2, 2, 2, 1, 2, 1, 3, 3};
		for (int i = 0; i < meat.length; i++) {
			m -= dif[i];
			if (s.charAt(m) != meat[i]) {
				good = false;
				break;
			}
		}
		return good;
	}

	public static boolean pizzaSauce(String s) {
		char[] sauce = {'b', 'p', 'u', 'b', 'r', 'n', 'r', 'c'};
		int a = 7; int b = 20; int i = 0; boolean good = true;
		while (a < b) {
			if (s.charAt(a) != sauce[i] || s.charAt(b) != sauce[i+1]) {
				good = false;
				break;
			}
			a++; b--; i += 2;
			while (!Character.isLetter(s.charAt(a))) a++;
			while (!Character.isLetter(s.charAt(b))) b--;
		}
		return good;
	}

	public static boolean veggies(String s) {
		int[] veg1 = {10, 12, 15, 22, 23, 25, 32, 36, 38, 40};
		int[] veg = new int[10];
		for (int i = 0; i < veg1.length; i++) {
			veg[i] = Integer.parseInt(s.substring(veg1[i], veg1[i]+1));
		}
		return (veg[0] + veg[1] == 14 && veg[1] * veg[2] == 20 && veg[2]/veg[3]/veg[4] == 1 && veg[3] == veg[4] && veg[3] == 2 && veg[4] - veg[5] == -3 && Math.pow(veg[5], veg[6]) == 125 && veg[7] == 4 && veg[8] % veg[7] == 3 && veg[8] + veg[9] == 9);
	}

	public static void main(String[] args) {
		Scanner in = new Scanner(System.in);
		System.out.println("Can burgers be pizzas? Try making a burger...");
		System.out.print("Enter flag: ");
		String input = in.next();
		in.close();

		boolean gotFlag = true;

		if (input.length() > 42) {
			System.out.println("This burger iz too big :(");
		} else if (input.length() < 42) {
			System.out.println("This burger iz too small :(");
		} else {
			if (!bun(input)) {
				System.out.println("Wrong bun >:0");
				gotFlag = false;
			}

			if (gotFlag) {
				if (!cheese(input)) {
					System.out.println("Hmph. Not good chez :/");
					gotFlag = false;
				}
			}

			if (gotFlag) {
				if (!meat(input)) {
					System.out.println("Bah, needs better meat :S");
					gotFlag = false;
				}
			}

			if (gotFlag) {
				if (!pizzaSauce(input)) {
					System.out.println("Tsk tsk. You call that pizza sauce? >:|");
					gotFlag = false;
				}
			}

			if (gotFlag) {
				if (!veggies(input)) {
					System.out.println("Rotten veggies, ew XP");
					gotFlag = false;
				}
			}

			if (gotFlag) {
				System.out.println("Yesyes good burger :D");
			}
		}

	}

}
```

There are multiple functions that check different parts of the flag. There are some things that we can quickly learn:

- The flag has length 42 (lines 61-64)
- The flag is wrapped with `LITCTF{` and `}` (lines 5-7, `bun()`)
- The `cheese` function (lines 9-11) seems to check for underscores at positions 13, 17, 19, 26, 29, 34, and 39.
- The `meat` function (lins 13-26) starts at index 41, then moves positions to check characters.

`pizzaSauce` checks two letters at a time, at `a` and `b`. It moves `a` and `b` based on `Character.isLetter`. Line 44 in `veggies` tells us the positions of numbers in the string:

```java=44
    int[] veg1 = {10, 12, 15, 22, 23, 25, 32, 36, 38, 40};
```

We can fill our test flag with `?` at these positions so `Character.isLetter()` returns `false` for them. Now, we can modify `pizzaSauce` to extract all the comparisons:


We can write a [https://github.com/Z3Prover/z3](z3 prover) script to find the 10 ints that satisfy these constraints:

```py=
from z3 import *

solver = Solver()

veg = [Int('veg_%d' % i) for i in range(10)]

for i in range(10):
    solver.add(veg[i] >= 0)
    solver.add(veg[i] < 10)

    # return (veg[0] + veg[1] == 14 && veg[1] * veg[2] == 20 &&
    #         veg[2] / veg[3] / veg[4] == 1 && veg[3] == veg[4] && veg[3] == 2 &&
    #         veg[4] - veg[5] == -3 && Math.pow(veg[5], veg[6]) == 125 &&
    #         veg[7] == 4 && veg[8] % veg[7] == 3 && veg[8] + veg[9] == 9);
solver.add(veg[0] + veg[1] == 14)
solver.add(veg[1] * veg[2] == 20)
# solver.add(veg[2] / veg[3] / veg[4] == 1)
solver.add(veg[3] == veg[4])
solver.add(veg[3] == 2)
solver.add(veg[4] - veg[5] == -3)
solver.add(veg[5] ** veg[6] == 125)
solver.add(veg[7] == 4)
solver.add(veg[8] % veg[7] == 3)
solver.add(veg[8] + veg[9] == 9)

print(solver.check())
model = solver.model()
for i in range(10):
    print(model[veg[i]])
```
